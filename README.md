## ✨ 功能特性 / Features

### 🇨🇳 中文说明

- ⏱ **30fps 实时进账跳动**：工作时间内以高频流畅动画显示当前分秒赚到的每一分钱，严格精确到小数点后两位。
- ☕️ **带薪摸鱼 / 如厕计时器**：内置摸鱼战报系统，实时统计摸鱼、喝咖啡或洗手间期间为老板赚取的薪水，结束后触发礼花庆祝动画并生成战报。
- 🌏 **深入适配 Tier 1 全球主流国情**：
  - 🇨🇳 **中国**：住房公积金（5%~12% 个人+单位 1:1 双倍进账）实时折算，真实中位数月薪预设（¥8,000）。
  - 🇫🇷 **法国**：Cadre / Non-cadre 社保分摊（~25%/22%）、RTT 调休假、Tickets Resto 饭补（€6/天）与 Navigo 50% 交通补贴折算，中位数预设（2 500 €）。
  - 🇩🇪 **德国**：法定养老保险 Rentenversicherung（雇员 9.3% + 雇主 9.3% 统筹）、28 天全额年假，中位数预设（3 500 €）。
  - 🇬🇧 **英国**：职业年金 Workplace Pension（员工 5% + 雇主 3% 强制匹配）、法定 28 天休假（含 Bank Holidays），中位数预设（£2,900）。
  - 🇯🇵 **日本**：社会保険（厚生年金 + 健康保险劳资对半）、16 天国民祝日（G7 最高），中位数预设（¥350,000）。
  - 🇺🇸 **美国**：401(k) 养老匹配、10 天联邦假与标准 PTO，中位数预设（$4,500）。
  - 🌐 **自定义**：自由定制合同币种、扣减费率与雇主补贴。
- 📊 **真实中位数薪资与精密假期联动**：
  - 提供“↺ 填入该国真实中位数”按钮，告别虚高数字。
  - 自动将法定节假日、带薪年假与调休假从年工作日中扣除——假期越多，每个实际工作日的身价与时薪就越高！
- 🎁 **丰富实物激励与大件心愿单**：
  - **日常小确幸**：星巴克拿铁、喜茶/霸王茶姬、豪华午餐、IMAX 电影票、10L 汽车汽油、Steam 3A 游戏大作、泰式全身 SPA。
  - **大件心愿进度**：AirPods Pro、iPhone 16 Pro、海岛度假机票、自定义心愿单，实时展示今天攒出的百分比进度条。
- 🪟 **迷你悬浮便签模式 (Mini Mode)**：
  - 一键收起为 280px 超窄便签卡，仅保留核心进账与实物胶囊，贴在屏幕边角不挡工作。
- ⌨️ **ESC 老板键 (Stealth Mode)**：
  - 紧急情况下按 `ESC` 键，界面瞬间伪装成极简工作日历时钟，再按 ESC 或双击恢复。
- 💾 **100% 离线隐私与自动记忆**：
  - 所有数据仅存储在浏览器本地 `localStorage`，无需登录注册，无隐私泄露风险，退出后再次打开自动恢复。

### 🇬🇧 English Description

- ⏱ **Real-Time 30fps Earnings Counter**: Watch your earnings tick up every fraction of a second during working hours, precisely formatted to 2 decimal places.
- ☕️ **Paid Slacking & Coffee Break Tracker**: Track every second of your paid breaks (coffee, bathroom, walking) and see exactly how much your company paid you to relax, complete with confetti celebrations.
- 🌏 **Deep Tier-1 Social System Integration**:
  - 🇨🇳 **China**: Housing Provident Fund (5%~12% with 1:1 employer match), realistic median wage preset (¥8,000/mo).
  - 🇫🇷 **France**: Cadre / Non-cadre cotisations (~25%/22%), RTT days, Tickets-Restaurant (€6/day) & Navigo transit 50%, median preset (€2,500/mo).
  - 🇩🇪 **Germany**: Statutory Pension Rentenversicherung (9.3% employee + 9.3% employer match), 28 paid vacation days, median preset (€3,500/mo).
  - 🇬🇧 **United Kingdom**: Workplace Pension Auto-Enrolment (5% employee + 3% employer match), 28 statutory days leave, median preset (£2,900/mo).
  - 🇯🇵 **Japan**: Social Insurance (Welfare Pension 9.15% + Health 5% split), 16 national public holidays, median preset (¥350,000/mo).
  - 🇺🇸 **United States**: 401(k) retirement plan with employer match, federal holidays & PTO, median preset ($4,500/mo).
  - 🌐 **Custom**: Freely customize benefits, matching rates, and currencies.
- 📊 **Realistic Medians & Exact Holiday Linkage**:
  - One-click "↺ Reset to National Median" button to prevent misleadingly high salary benchmarks.
  - Automatically subtracts statutory holidays and vacation from total working days—having more holidays mathematically increases your hourly and daily earnings!
- 🎁 **Real-World Rewards & Milestone Wishlists**:
  - Daily rewards: Starbucks Latte, Boba Tea, Deluxe Lunch, IMAX Movie Tickets, 10L Gasoline, Steam 3A Games, Thai Massage.
  - Big goals with progress bars: AirPods Pro, iPhone 16 Pro, Flight Tickets, Custom Wishlist.
- 🪟 **Mini Floating Mode**:
  - One-click collapse into a compact widget showing only earnings and rewards, ideal for keeping in a screen corner while working.
- ⌨️ **Stealth Boss Key (ESC)**:
  - Hit `ESC` to instantly disguise the interface as a clean minimalist calendar clock.
- 💾 **100% Privacy & Offline Local Storage**:
  - All configurations are stored locally in your browser; no backend databases, zero trackers, completely private.

## 🛠 本地开发与构建 / Local Development

```bash
# 1. 克隆代码 / Clone repository
git clone https://github.com/SpaceSheepBoy/salary-push-web.git
cd salary-push-web

# 2. 安装依赖 / Install dependencies
npm install

# 3. 启动本地开发服务 / Start development server
npm run dev

# 4. 构建生产版本 / Build for production
npm run build
```
